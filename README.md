# THE DEMAND FOR BULLSHIT

A research website exploring why low-quality information persists and spreads in media, academia, and public discourse. This project investigates the psychological, social, and institutional factors that create demand for misinformation, and develops interventions to improve epistemic quality in information ecosystems.

The site presents our research on assessing the problem, measuring information quality, and testing interventions-including tools like prediction trackers and fallacy detectors that help evaluate the credibility of content creators and media sources.
